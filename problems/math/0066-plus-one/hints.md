# 66. Plus One — Hints / Gợi ý

## Hint 1

**EN:** Addition starts at the least significant digit, so scan from right to left.

**VI:** Phép cộng bắt đầu ở chữ số hàng thấp nhất, vì vậy hãy duyệt từ phải sang trái.

## Hint 2

**EN:** If a digit is less than 9, increment it and return immediately.

**VI:** Nếu chữ số nhỏ hơn 9, tăng nó lên 1 và có thể trả kết quả ngay.

## Hint 3

If a digit is 9, it becomes 0 and the carry continues. Only an all-9 input needs a longer output array.
