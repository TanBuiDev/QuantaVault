# 9. Palindrome Number

## Difficulty / Độ khó

**Easy / Dễ**

## Problem / Đề bài

> **EN:** Given an integer x, return true if x is a palindrome, and false otherwise.
>
> **VI:** Cho số nguyên `x`, trả về `true` nếu `x` là số palindrome và `false` nếu không phải.

## Examples / Ví dụ

### Example 1 / Ví dụ 1
```text
Input: x = 121
Output: true
Explanation: 121 reads as 121 from left to right and from right to left.
```

### Example 2 / Ví dụ 2
```text
Input: x = -121
Output: false
```

### Example 3 / Ví dụ 3
```text
Input: x = 10
Output: false
```

## Constraints / Ràng buộc

> **EN:** `-2^31 <= x <= 2^31 - 1`
>
> **VI:** `x` nằm trong miền số nguyên 32-bit có dấu.

## Follow-up / Câu hỏi mở rộng

> **EN:** Could you solve it without converting the integer to a string?
>
> **VI:** Bạn có thể giải mà không chuyển integer thành string không?
