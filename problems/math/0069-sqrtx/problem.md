# 69. Sqrt(x)

## Difficulty / Độ khó

**Easy / Dễ**

## Problem / Đề bài

> **EN:** Given a non-negative integer `x`, return the square `root` of `x` rounded down to the nearest integer. The returned integer should be non-negative as well.
>
> **VI:** Cho số nguyên không âm `x`, hãy trả về căn bậc hai của `x` sau khi làm tròn xuống số nguyên gần nhất. Kết quả cũng phải không âm.

> **EN:** You must not use any built-in exponent function or operator.
>
> **VI:** Không được dùng hàm hoặc toán tử lũy thừa dựng sẵn.

## Examples / Ví dụ

### Example 1 / Ví dụ 1

```text
Input: x = 4
Output: 2
```

### Example 2 / Ví dụ 2

```text
Input: x = 8
Output: 2
```

## Constraints / Ràng buộc

> **EN:** `0 <= `x` <= 2^31 - 1`
>
> **VI:** `0 <= x <= 2^31 - 1`
