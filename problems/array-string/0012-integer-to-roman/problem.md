# 12. Integer to Roman

## Difficulty / Độ khó

**Medium / Trung bình**

## Problem / Đề bài

> **EN:** Seven different symbols represent Roman numerals with the following values: I=1, V=5, X=10, L=50, C=100, D=500 and M=1000.
>
> **VI:** Bảy ký hiệu La Mã có giá trị: `I=1`, `V=5`, `X=10`, `L=50`, `C=100`, `D=500`, `M=1000`.

> **EN:** Roman numerals are formed by appending the conversions of decimal place values from highest to lowest. Subtractive forms are used for 4 (IV), 9 (IX), 40 (XL), 90 (XC), 400 (CD) and 900 (CM).
>
> **VI:** Số La Mã được tạo từ giá trị lớn xuống nhỏ. Các dạng trừ là `IV, IX, XL, XC, CD, CM` tương ứng `4,9,40,90,400,900`.

> **EN:** Given an integer, convert it to a Roman numeral.
>
> **VI:** Cho một số nguyên, hãy chuyển nó thành số La Mã.

## Examples / Ví dụ

```text
Input: num = 3749
Output: "MMMDCCXLIX"
```

```text
Input: num = 58
Output: "LVIII"
```

```text
Input: num = 1994
Output: "MCMXCIV"
```

## Constraints / Ràng buộc

> **EN:** `1 <= `num` <= 3999`
>
> **VI:** `1 <= num <= 3999`
