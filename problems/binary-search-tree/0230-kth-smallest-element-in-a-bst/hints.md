# Hints / Gợi ý — 230. Kth Smallest Element in a BST

## Hint 1
**EN:** Inorder traversal of a BST visits values in ascending order.

**VI:** Inorder traversal của BST thăm value theo thứ tự tăng dần.

## Hint 2
**EN:** You do not need to finish the traversal after seeing `k` values.

**VI:** Không cần hoàn tất traversal sau khi đã thấy `k` value.

## Hint 3
**EN:** An explicit stack lets you stop immediately when the kth node is popped.

**VI:** Explicit stack cho phép dừng ngay khi pop node thứ `k`.
