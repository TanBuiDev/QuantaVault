# Hints / Gợi ý — 530. Minimum Absolute Difference in BST

## Hint 1
**EN:** Inorder traversal of a BST produces values in increasing order.

**VI:** Inorder traversal của BST tạo value theo thứ tự tăng dần.

## Hint 2
**EN:** In a sorted sequence, the minimum difference must occur between adjacent values.

**VI:** Trong một sorted sequence, minimum difference luôn xuất hiện giữa hai value kề nhau.

## Hint 3
**EN:** Keep only the previous inorder value and the best difference so far.

**VI:** Chỉ cần giữ previous inorder value và best difference hiện tại.
