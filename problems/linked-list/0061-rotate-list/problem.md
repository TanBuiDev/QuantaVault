# 61. Rotate List

## Difficulty / Độ khó

**Medium / Trung bình**

## Problem / Đề bài

> **EN:** Given the `head` of a linked list, `rotate` the list to the `right` by `k` places.
>
> **VI:** Cho `head` của một linked list. Hãy xoay list sang phải `k` vị trí.

## Examples / Ví dụ

### Example 1 / Ví dụ 1

```text
Input: head = [1,2,3,4,5], k = 2
Output: [4,5,1,2,3]
```

### Example 2 / Ví dụ 2

```text
Input: head = [0,1,2], k = 4
Output: [2,0,1]
```

## Constraints / Ràng buộc

> **EN:** The number of nodes in the list is in the range [0, 500].
>
> **VI:** Số node nằm trong `[0, 500]`.

> **EN:** -100 <= `Node`.val <= 100
>
> **VI:** `Node.val` nằm trong `[-100, 100]`.

> **EN:** 0 <= `k` <= 2 * 10^9
>
> **VI:** `0 <= k <= 2 * 10^9`.
