# 53. Maximum Subarray

## Difficulty / Độ khó
**Medium / Trung bình**

## Problem / Đề bài
> **EN:** Given an integer array `nums`, find the subarray with the largest sum and return its sum.
>
> **VI:** Cho mảng số nguyên `nums`, hãy tìm subarray có tổng lớn nhất và trả về tổng đó.

## Examples / Ví dụ
```text
[-2,1,-3,4,-1,2,1,-5,4] -> 6
[1] -> 1
[5,4,-1,7,8] -> 23
```

## Constraints / Ràng buộc
> **EN:** `1 <= `nums`.length <= 10^5`; `-10^4 <= `nums[i]` <= 10^4`.
>
> **VI:** Mảng không rỗng và giá trị nằm trong phạm vi đề bài.

## Follow-up / Câu hỏi mở rộng
> **EN:** After the O(n) solution, try a divide-and-conquer solution.
>
> **VI:** Sau lời giải O(n), hãy thử giải bằng divide and conquer.
