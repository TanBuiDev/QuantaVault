# 918. Maximum Sum Circular Subarray

## Difficulty / Độ khó
**Medium / Trung bình**

## Problem / Đề bài
> **EN:** Given a circular integer array `nums`, return the maximum possible sum of a non-empty subarray. The end connects to the beginning, and each fixed-buffer element may be used at most once.
>
> **VI:** Cho mảng số nguyên vòng `nums`, hãy trả về tổng lớn nhất của một subarray không rỗng. Cuối mảng nối với đầu và mỗi phần tử chỉ được dùng tối đa một lần.

## Examples / Ví dụ
```text
[1,-2,3,-2] -> 3
[5,-3,5] -> 10
[-3,-2,-3] -> -2
```

## Constraints / Ràng buộc
> **EN:** `1 <= n <= 3*10^4`; values are in `[-3*10^4,3*10^4]`.
>
> **VI:** Mảng không rỗng và các giá trị nằm trong phạm vi đề bài.
