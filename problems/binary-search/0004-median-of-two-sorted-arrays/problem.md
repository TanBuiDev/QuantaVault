# 4. Median of Two Sorted Arrays

## Difficulty / Độ khó

**Hard / Khó**

## Problem / Đề bài

> **EN:** Given two sorted arrays nums1 and nums2 of size m and n respectively, return the median of the two sorted arrays.
>
> **VI:** Cho hai mảng đã sắp xếp `nums1`, `nums2` có kích thước `m`, `n`, hãy trả về median của hai mảng kết hợp.

> **EN:** The overall run time complexity should be O(log (m+n)).
>
> **VI:** Độ phức tạp thời gian tổng thể phải là `O(log(m+n))`.

## Examples / Ví dụ

```text
Input: nums1 = [1,3], nums2 = [2]
Output: 2.0
```

```text
Input: nums1 = [1,2], nums2 = [3,4]
Output: 2.5
```

## Constraints / Ràng buộc

> **EN:** `0 <= m,n <= 1000`, `1 <= m+n <= 2000`, values are in `[-10^6,10^6]`.
>
> **VI:** Một mảng có thể rỗng nhưng tổng số phần tử ít nhất là 1; các giá trị nằm trong phạm vi đề bài.
