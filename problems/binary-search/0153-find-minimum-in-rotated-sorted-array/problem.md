# 153. Find Minimum in Rotated Sorted Array

## Difficulty / Độ khó
**Medium / Trung bình**

## Problem / Đề bài
> **EN:** Given the sorted rotated array `nums` of unique elements, return the minimum element. You must write an algorithm that runs in `O(log n)` time.
>
> **VI:** Cho mảng tăng dần gồm các phần tử duy nhất đã bị xoay, hãy trả về phần tử nhỏ nhất trong `O(log n)`.

## Examples / Ví dụ
```text
Input: nums = [3,4,5,1,2]
Output: 1
```
```text
Input: nums = [4,5,6,7,0,1,2]
Output: 0
```
```text
Input: nums = [11,13,15,17]
Output: 11
```

## Constraints / Ràng buộc
> **EN:** `1 <= `nums`.length <= 5000`; all values are unique; `nums` is sorted and rotated between 1 and n times.
>
> **VI:** Mảng không rỗng, các giá trị duy nhất, và là một mảng tăng dần đã xoay.
