# Hints / Gợi ý — 210. Course Schedule II

## Hint 1
**EN:** This is a topological ordering problem on the prerequisite graph.

**VI:** Đây là bài topological ordering trên prerequisite graph.

## Hint 2
**EN:** Start with all courses whose indegree is zero.

**VI:** Bắt đầu từ mọi course có indegree bằng zero.

## Hint 3
**EN:** If fewer than `numCourses` nodes are output, a cycle exists and no valid order is possible.

**VI:** Nếu output ít hơn `numCourses` node thì có cycle và không tồn tại thứ tự hợp lệ.
