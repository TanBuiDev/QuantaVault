# 101. Symmetric Tree

## Difficulty / Độ khó

**Easy / Dễ**

## Problem / Đề bài

> **EN:** Given the root of a binary tree, check whether it is a mirror of itself (i.e., symmetric around its center).
>
> **VI:** Cho `root` của một binary tree. Hãy kiểm tra cây có phải là ảnh gương của chính nó, tức đối xứng qua tâm, hay không.

## Examples / Ví dụ

### Example 1 / Ví dụ 1

```text
Input: root = [1,2,2,3,4,4,3]
Output: true
```

### Example 2 / Ví dụ 2

```text
Input: root = [1,2,2,null,3,null,3]
Output: false
```

## Constraints / Ràng buộc

> **EN:** The number of nodes in the tree is in the range [1, 1000].
>
> **VI:** Số node trong tree nằm trong `[1, 1000]`.

> **EN:** -100 <= Node.val <= 100
>
> **VI:** `Node.val` nằm trong `[-100, 100]`.

## Follow-up / Câu hỏi mở rộng

> **EN:** Could you solve it both recursively and iteratively?
>
> **VI:** Bạn có thể giải bài bằng cả recursion lẫn iteration không?
