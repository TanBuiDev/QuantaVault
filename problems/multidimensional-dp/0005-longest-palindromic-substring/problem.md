# 5. Longest Palindromic Substring

## Difficulty / Độ khó

**Medium / Trung bình**

## Problem / Đề bài

> **EN:** Given a string s, return the longest palindromic substring in s.
>
> **VI:** Cho một chuỗi `s`, hãy trả về chuỗi con liên tiếp đối xứng dài nhất trong `s`.

## Examples / Ví dụ

### Example 1 / Ví dụ 1

```text
Input: s = "babad"
Output: "bab"
```

> **EN:** Explanation: "aba" is also a valid answer.
>
> **VI:** `"aba"` cũng là một đáp án hợp lệ.

### Example 2 / Ví dụ 2

```text
Input: s = "cbbd"
Output: "bb"
```

## Constraints / Ràng buộc

> **EN:** `1 <= s.length <= 1000`
>
> **VI:** Độ dài `s` từ `1` đến `1000`.

> **EN:** `s consist of only digits and English letters.`
>
> **VI:** `s` chỉ gồm chữ số và chữ cái tiếng Anh.
