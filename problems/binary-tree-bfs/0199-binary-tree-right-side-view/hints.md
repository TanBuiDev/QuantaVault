# Hints / Gợi ý — 199. Binary Tree Right Side View

## Hint 1
**EN:** The answer contains one value per non-empty level.

**VI:** Đáp án chứa một value cho mỗi level không rỗng.

## Hint 2
**EN:** In left-to-right BFS, the last node processed in a level is the visible node from the right.

**VI:** Trong BFS trái sang phải, node cuối của mỗi level là node nhìn thấy từ bên phải.

## Hint 3
**EN:** Capture the queue size before processing each level.

**VI:** Lưu queue size trước khi xử lý mỗi level.
