# Hints / Gợi ý — 637. Average of Levels in Binary Tree

## Hint 1
**EN:** BFS naturally groups nodes by level.

**VI:** BFS tự nhiên gom node theo từng level.

## Hint 2
**EN:** Save the level size before polling its nodes.

**VI:** Lưu level size trước khi poll các node.

## Hint 3
**EN:** Accumulate with `double` so a large integer sum cannot overflow before division.

**VI:** Cộng bằng `double` để tổng lớn không overflow trước phép chia.
