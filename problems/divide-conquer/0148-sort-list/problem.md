# 148. Sort List

## Difficulty / Độ khó
**Medium / Trung bình**

## Problem / Đề bài
> **EN:** Given the `head` of a linked list, return the list after sorting it in ascending order.
>
> **VI:** Cho `head` của linked list, hãy trả về list sau khi sắp xếp tăng dần.

## Examples / Ví dụ
```text
Input: [4,2,1,3]
Output: [1,2,3,4]
```
```text
Input: [-1,5,3,4,0]
Output: [-1,0,3,4,5]
```
```text
Input: []
Output: []
```

## Constraints / Ràng buộc
> **EN:** The number of nodes is in `[0, 5 * 10^4]`; node values are in `[-10^5, 10^5]`.
>
> **VI:** List có từ 0 đến `5 * 10^4` node; giá trị node nằm trong phạm vi đề bài.

## Follow-up / Câu hỏi mở rộng
> **EN:** Can you sort the linked list in `O(n log n)` time and `O(1)` memory?
>
> **VI:** Có thể sort trong `O(n log n)` time và `O(1)` memory không?
