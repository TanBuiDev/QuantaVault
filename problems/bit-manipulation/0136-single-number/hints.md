# 136. Single Number — Hints / Gợi ý

## Hint 1

**EN:** XOR has the identities `x ^ x = 0` and `x ^ 0 = x`.

**VI:** XOR có các tính chất `x ^ x = 0` và `x ^ 0 = x`.

## Hint 2

**EN:** XOR is associative and commutative, so the order of values does not matter.

**VI:** XOR có tính kết hợp và giao hoán, nên thứ tự các phần tử không quan trọng.

## Hint 3

XOR every element together; all paired values cancel and only the unique value remains.
