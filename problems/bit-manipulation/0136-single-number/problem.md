# 136. Single Number

## Difficulty / Độ khó

**Easy / Dễ**

## Problem / Đề bài

> **EN:** Given a non-empty array of integers `nums`, every element appears twice except for one. Find that single one.
>
> **VI:** Cho mảng số nguyên không rỗng `nums`, mọi phần tử xuất hiện hai lần ngoại trừ một phần tử xuất hiện một lần. Hãy tìm phần tử đó.

> **EN:** You must implement a solution with a linear runtime complexity and use only constant extra space.
>
> **VI:** Lời giải phải chạy tuyến tính và dùng bộ nhớ phụ hằng số.

## Examples / Ví dụ

```text
Input: nums = [2,2,1]
Output: 1
```

```text
Input: nums = [4,1,2,1,2]
Output: 4
```

```text
Input: nums = [1]
Output: 1
```

## Constraints / Ràng buộc

> **EN:** `1 <= `nums`.length <= 3 * 10^4`
>
> **VI:** Mảng có từ 1 đến `3 * 10^4` phần tử.

> **EN:** `-3 * 10^4 <= `nums[i]` <= 3 * 10^4`
>
> **VI:** Mỗi giá trị nằm trong khoảng đã cho.

> **EN:** Each element in the array appears twice except for one element which appears only once.
>
> **VI:** Mỗi phần tử xuất hiện hai lần, trừ một phần tử xuất hiện một lần.
