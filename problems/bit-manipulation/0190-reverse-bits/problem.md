# 190. Reverse Bits

## Difficulty / Độ khó

**Easy / Dễ**

## Problem / Đề bài

> **EN:** Reverse bits of a given 32 bits signed integer.
>
> **VI:** Hãy đảo thứ tự 32 bit của số nguyên có dấu đã cho.

## Examples / Ví dụ

```text
Input: n = 43261596
Output: 964176192
```

```text
Input: n = 2147483644
Output: 1073741822
```

## Constraints / Ràng buộc

> **EN:** `0 <= n <= 2^31 - 2`
>
> **VI:** `n` nằm trong khoảng từ 0 đến `2^31 - 2`.

> **EN:** `n` is even.
>
> **VI:** `n` là số chẵn.

>
> **VI:** Nếu hàm được gọi nhiều lần, bạn sẽ tối ưu thế nào?
