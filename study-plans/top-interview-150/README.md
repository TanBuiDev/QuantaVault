# Top Interview 150

This directory tracks the Top Interview 150 study plan for this private study repository.

## Migration policy

- Canonical problem content is migrated only from source text already supplied by the repository owner in this repository, uploaded files, or retrievable prior study conversations.
- Supplied LeetCode wording is preserved rather than replaced with a paraphrase.
- Missing source text is an expected state and will be added later by the repository owner.
- A problem is not considered fully migrated until its canonical source statement is available.
- Existing completed Java solutions are migrated and verified before new solutions are generated.

## Coverage states

- `pending` — supplied source exists but canonical migration has not finished.
- `migrated` — canonical problem folder has been created and validated.
- `source-missing` — problem identity is known but the original source text has not yet been supplied to the migration process.

The ordered `index.yaml` will be expanded from verified repository inventory rather than guessed or filled with fabricated content.
